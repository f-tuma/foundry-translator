# MiLMMT 12B Q4_K_S local evaluation, 2026-09-21

The user installed MiLMMT and prefers a smaller, faster model. The installed
build is fast at ordinary prose, but it did not reliably follow the reviewed
glossary or preserve protected markup in these tests. It is not selected as a
replacement for Hy-MT2 7B. No production provider, Foundry setting or glossary
was changed. Larger-model downloads are not a prerequisite for continuing.

## Model and method

LM Studio ID: `milmmt-46-12b-v1.0`. Publisher of the GGUF: `mradermacher`.
Server-reported quantization: Q4_K_S; file size 7,789,533,216 bytes (~7.8 GB).
Loaded context: 8,192; flash attention enabled; no speculative draft.
Host: RTX 5070 Ti with 16 GB VRAM, approximately 64 GB RAM.

The [publisher's model card](https://huggingface.co/xiaomi-research/MiLMMT-46-12B-v1.0)
documents raw text completion with language names, rather than a generic chat
conversation. Tests used this format through `/v1/completions`, temperature 0:

```text
Translate this from English to Czech:
English: <source>
Czech:
```

LM Studio's [completion endpoint](https://lmstudio.ai/docs/developer/openai-compat/completions)
does not apply a chat template. One chat comparison was also run; it degenerated
into repeated markup and reached the diagnostic 700-token limit. The raw
completion tests ensure that conclusion is not based solely on an unsuitable
chat template. All source passages are authored synthetic examples.

## Results

Four narrative passages matched the preceding model comparison: creature
tracks, a defended bridge, a conversation before departure, and a return with
a UUID link. Each was translated separately, first without terminology and
then with the relevant approved names before the official translation prompt.

| Mode | Four-paragraph elapsed time | Output tokens | Findings |
| --- | --- | --- | --- |
| Raw completion, no glossary | 2.81 s | 193 | Readable Czech and the intended ownership/negation; invented names such as Staré Korutě and Staré Korintie |
| Raw completion with terminology | 2.78 s | 186 | Still ignored approved names; one UUID label became a formatting escape instead of a name |

These are warm-model request totals. The earlier first paragraph request took
3.03 seconds including initial auto-load overhead. They are **not** directly
comparable to the prior Hy-MT2 production time of 8.6 seconds: that pipeline
includes protection, structured output and validation. MiLMMT's speed is
promising, but it has not delivered the same functionality.

Examples from the terminology run:

| Approved name | Actual result |
| --- | --- |
| Spirit Beasts → Přízračné Šelmy | Duchovním bestiím |
| Delvers → Permoníci | Delverů |
| Old Carinth → Starý Carinth | Starého Karintu |
| Brackus von Tet → Brackus Z Tetu | Brackusem von Tetem |
| UUID label Old Carinth → a form of Starý Carinth | `@UUID[Scene.old]{\cH00FFFF\}` |

Eight additional input variations tested a terminology prefix, a single XML
name, canonical Czech names inserted into English, simple HTML, few-shot
name translations, and paired/fixed ASCII markers. None supplied a reliable
combination of approved terminology, natural inflection and preserved structure.
Mixed-language input produced `Permoňanům` and `Starého Korutanu`. Simple HTML
was removed and separate clauses were merged, changing their relationship.
An opaque fixed marker survived in one sentence, but the model added
“z místa s názvem” and provided no evidence for the required inflection.

The correct grammatical relation in the ordinary Spirit Beasts paragraph is
encouraging. It does not compensate for renaming the creatures. Conversely,
this small test of one community quantization does not establish that every
MiLMMT build behaves identically. No causal claim about quantization is made.

## Decision and reproduction

Keep Hy-MT2 7B as the current smaller-model baseline: it follows the selected
terminology substantially better in the existing pipeline, although its Czech
inflection still needs work. Do not introduce a MiLMMT production adapter that
would silently discard glossary choices. PR #19 remains draft; the all-inflect
import is still unapproved by real language-quality checks.

```sh
LM_STUDIO_RESULT=/tmp/milmmt-paragraphs.json node scripts/benchmark-milmmt.mjs
```

`LM_STUDIO_MODEL` and `LM_STUDIO_URL` optionally select a different local ID or
server. The script uses bounded output and request timeouts and saves each
completed result. It is a diagnostic, not a passing/failing grammar test and
not an automatic part of CI. The executable script passed `node --check` and
completed all eight recorded paragraph requests. Production code is unchanged.
